# Vision_PC

Aplicación desarrollada en C++ con OpenCV.

## Función

- Captura video desde una cámara IP.
- Detecta marcadores ArUco.
- Calcula el ángulo del péndulo.
- Envía el ángulo al ESP32 mediante UDP.

## Requisitos para compilar

- Visual Studio Code
- CMake
- OpenCV
- Compilador de C++ (g++ o MSVC)
